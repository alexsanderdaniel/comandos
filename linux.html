Navegação

Navegação e localização

pwdMostra o caminho completo da pasta atual.
lsLista arquivos e pastas.
ls -laInclui arquivos ocultos e permissões.
cd nome_da_pastaEntra em uma pasta.
cd ..Volta uma pasta.
cd ~Vai para a Home.
cd /Vai para a raiz.
clearLimpa o terminal.
Arquivos

Criar, copiar, mover e renomear

mkdir nova_pastaCria uma pasta.
mkdir -p pasta/subpastaCria pastas encadeadas.
touch arquivo.txtCria arquivo vazio.
cp arquivo.txt destino/Copia um arquivo.
cp -r pasta destino/Copia uma pasta.
mv arquivo.txt destino/Move um arquivo.
mv antigo.txt novo.txtRenomeia um arquivo.
mv pasta_antiga pasta_novaRenomeia uma pasta.
Arquivos

Excluir e consultar

rm arquivo.txtExclui um arquivo.
rmdir pastaExclui uma pasta vazia.
rm -r pastaExclui pasta e conteúdo.
rm -rf pastaForça exclusão recursiva.
cat arquivo.txtExibe conteúdo de texto.
less arquivo.txtLeitura paginada.
historyMostra comandos anteriores.
Atenção

Antes de usar rm -r ou rm -rf, confirme a pasta com pwd e ls.

Pesquisa

Pesquisa

find . -name "arquivo.txt"Procura arquivo a partir da pasta atual.
grep -R "texto" .Procura texto dentro dos arquivos.
grep -n "texto" arquivo.txtMostra linhas que contêm o texto.
which phpMostra o caminho de um executável.
Permissões

Permissões e proprietário

sudo comandoExecuta um comando com privilégios de administrador.
chmod +x arquivo.shDá permissão de execução.
chmod 755 arquivo.shDefine permissões numéricas comuns para script.
sudo chown -R $USER:$USER pastaTorna o usuário atual proprietário da pasta.
whoamiMostra o usuário atual.
Sistema

Sistema e armazenamento

df -hMostra espaço disponível nos discos.
du -sh pastaMostra o tamanho de uma pasta.
lsblk -fExibe discos, partições e sistemas de arquivos.
free -hMostra uso de memória.
uname -aInformações do kernel e sistema.
Diagnóstico

Processos e portas

ps auxLista processos.
topAcompanha processos em tempo real.
kill PIDSolicita encerramento de um processo.
sudo ss -ltnpMostra portas TCP em uso.
sudo ss -ltnp | grep ':80'Procura processo usando a porta 80.
Pacotes

Pacotes Debian/Ubuntu

sudo apt updateAtualiza a lista de pacotes.
sudo apt upgradeAtualiza pacotes instalados.
sudo apt install NOMEInstala um pacote.
sudo apt remove NOMERemove um pacote.
