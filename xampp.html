Preparação

Parar serviços que causam conflito

Comandos 
sudo systemctl stop apache2
sudo systemctl stop mysql
sudo systemctl stop mariadb

Isso pode liberar as portas que o Apache e o MySQL do XAMPP precisam usar.

Serviços

Iniciar, parar e reiniciar

sudo /opt/lampp/lampp startInicia os serviços do XAMPP.
sudo /opt/lampp/lampp statusMostra o status.
sudo /opt/lampp/lampp stopPara os serviços.
sudo /opt/lampp/lampp restartReinicia o XAMPP.
Diagnóstico

Diagnosticar portas

sudo ss -ltnp | grep -E ':80|:443|:3306'Mostra processos usando portas do Apache/HTTPS/MySQL.
sudo /opt/lampp/bin/httpd -tTesta a configuração do Apache; o esperado é Syntax OK.
sudo tail -n 50 /opt/lampp/logs/error_logMostra erros recentes do Apache.
sudo tail -n 50 /opt/lampp/var/mysql/*.errMostra erros recentes do MySQL.
Projetos

htdocs e projetos

cd /opt/lampp/htdocsEntra na pasta pública do Apache.
sudo mkdir /opt/lampp/htdocs/projetoCria uma pasta de projeto.
sudo cp -r ~/Downloads/NOME_DO_PROJETO /opt/lampp/htdocs/Copia projeto para htdocs.
sudo chown -R $USER:$USER /opt/lampp/htdocs/projetoPermite ao usuário editar o projeto.
Navegador

Endereços locais

http://localhostPágina inicial local.
http://localhost/phpmyadminAbre phpMyAdmin.
http://localhost/NOME_DO_PROJETO/Abre um projeto em htdocs.
Checklist

Rotina após reiniciar

Sequência rápida 
sudo systemctl stop apache2
sudo systemctl stop mysql
sudo systemctl stop mariadb
sudo /opt/lampp/lampp start
sudo /opt/lampp/lampp status
Observação

Se um serviço como MariaDB não estiver instalado, o sistema pode informar que a unidade não existe.
