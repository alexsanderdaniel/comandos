Importante: MySQL e GitHub Pages

Conteúdo de referência

GitHub Pages não fornece um servidor MySQL. Os comandos abaixo são apresentados somente para estudo e consulta.

Terminal

Acessar pelo terminal

mysql -u root -pAbre o cliente MySQL solicitando senha.
SHOW DATABASES;Lista bancos.
USE nome_banco;Seleciona um banco.
SHOW TABLES;Lista tabelas.
DESCRIBE nome_tabela;Mostra a estrutura.
exitSai do cliente.
DDL

Criar banco e tabela

SQL
CREATE DATABASE empresa;
USE empresa;

CREATE TABLE cliente (
  id INT PRIMARY KEY AUTO_INCREMENT,
  nome VARCHAR(100) NOT NULL,
  email VARCHAR(150) UNIQUE
);
INSERT

Inserir dados

SQL
INSERT INTO cliente (nome, email)
VALUES ('Ana', 'ana@email.com');
SELECT

Consultar dados

SQL
SELECT * FROM cliente;
SELECT nome, email FROM cliente ORDER BY nome;
SELECT * FROM cliente WHERE id = 1;
DML

Atualizar e excluir

SQL
UPDATE cliente
SET email = 'novo@email.com'
WHERE id = 1;

DELETE FROM cliente WHERE id = 1;
Atenção

Em UPDATE e DELETE, confira o WHERE antes de executar para evitar alterar todos os registros.

Relacionamento

Chave estrangeira

SQL
CREATE TABLE pedido (
  id INT PRIMARY KEY AUTO_INCREMENT,
  cliente_id INT NOT NULL,
  data_pedido DATE,
  FOREIGN KEY (cliente_id) REFERENCES cliente(id)
);
Consulta

JOIN

SQL
SELECT p.id, c.nome, p.data_pedido
FROM pedido p
INNER JOIN cliente c ON c.id = p.cliente_id;
DDL

Alterar estrutura

ALTER TABLE cliente ADD telefone VARCHAR(20);Adiciona coluna.
ALTER TABLE cliente MODIFY nome VARCHAR(150);Altera definição.
ALTER TABLE cliente DROP COLUMN telefone;Remove coluna.
