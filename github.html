Remoto

Conectar um projeto ao GitHub

Depois de criar um repositório vazio no GitHub:

Comandos
git branch -M main
git remote add origin https://github.com/USUARIO/REPOSITORIO.git
git push -u origin main
Rotina

Atualizar o GitHub

Comandos
git status
git add .
git commit -m "Descrição da alteração"
git push

Esse é o fluxo mais usado após o primeiro envio.

Sincronização

Clonar e sincronizar

git clone URL_DO_REPOSITORIOBaixa uma cópia completa do repositório.
git pullBaixa e integra alterações remotas.
git fetchAtualiza referências remotas sem mesclar.
git pull --rebaseAtualiza reposicionando seus commits locais.
Remoto

Gerenciar origin

git remote -vExibe URLs remotas.
git remote set-url origin NOVA_URLTroca a URL do origin.
git remote remove originRemove o origin atual.
Erro comum

Se aparecer remote origin already exists, altere a URL com git remote set-url origin ....

GitHub Pages

GitHub Pages

Publica sites estáticos diretamente a partir do repositório.

  1. 1
    Abra Settings no repositório.
  2. 2
    Entre em Pages.
  3. 3
    Em Source, escolha Deploy from a branch.
  4. 4
    Selecione main e /(root).
  5. 5
    Clique em Save e aguarde a publicação.
https://USUARIO.github.io/REPOSITORIO/
Colaboração

Issues

Use Issues para registrar bugs, tarefas, melhorias e dúvidas. Um bom título descreve o problema e a descrição deve explicar contexto, passos e resultado esperado.

Colaboração

Pull Requests

Pull Requests permitem revisar alterações de uma branch antes de integrá-las à principal. Fluxo típico:

  1. 1
    Crie uma branch.
  2. 2
    Faça alterações e commits.
  3. 3
    Envie a branch com git push -u origin branch.
  4. 4
    Abra um Pull Request no GitHub.
  5. 5
    Revise e faça o merge.

Segurança

Repositório público x privado

Público: qualquer pessoa pode visualizar o código. Privado: apenas pessoas autorizadas têm acesso. Mesmo em repositório privado, evite versionar credenciais.
