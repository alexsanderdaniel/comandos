Configuração

Configuração inicial

Faça uma vez em cada computador. Use preferencialmente o mesmo nome e e-mail da sua conta do GitHub.

Comandos
git config --global user.name "Seu Nome"
git config --global user.email "seuemail@exemplo.com"
git config --global --list
Começo

Iniciar um repositório local

Comandos
git init
git status
O que acontece?

O comando git init cria a estrutura interna do Git na pasta atual.

Commit

Primeiro commit

Comandos
git add .
git commit -m "Primeiro commit"

git add . prepara as alterações e git commit registra uma versão no histórico local.

Dia a dia

Commits seguintes

git statusConfere o que foi alterado.
git add .Adiciona todas as alterações ao stage.
git commit -m "Descrição"Cria um novo commit.
git log --onelineMostra o histórico resumido.
Inspeção

Inspecionar alterações

git diffCompara alterações ainda fora do stage.
git diff --stagedMostra alterações já adicionadas ao stage.
git showExibe detalhes do commit atual.
git log --graph --oneline --allExibe histórico em forma de grafo.
Branches

Branches

git branchLista branches.
git switch -c recursoCria e entra em uma branch.
git switch mainVolta para main.
git merge recursoMescla a branch recurso na atual.
git branch -d recursoRemove branch local já mesclada.
Organização

Stash

git stashGuarda alterações temporariamente.
git stash listLista os stashes.
git stash popRestaura e remove o stash mais recente.
git stash applyRestaura sem remover o stash.
Recuperação

Desfazer com segurança

git restore arquivo.txtDescarta alteração local não adicionada.
git restore --staged arquivo.txtRetira um arquivo do stage.
git revert HASHCria um commit que desfaz outro commit.
git reset --soft HEAD~1Remove o último commit mantendo as alterações.
Cuidado

Evite git reset --hard quando não tiver certeza, pois ele pode descartar alterações locais.

Versões

Tags e versões

git tagLista tags.
git tag -a v1.0.0 -m "Versão 1.0"Cria uma tag anotada.
git push origin v1.0.0Publica a tag específica.
git push origin --tagsPublica todas as tags.
Segurança

.gitignore

Evita que arquivos desnecessários ou sensíveis entrem no versionamento.

.gitignore
.env
node_modules/
vendor/
*.log
.DS_Store
.vscode/
Segurança

Nunca coloque senhas, tokens, chaves privadas ou credenciais reais no repositório.
