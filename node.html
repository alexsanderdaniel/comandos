Atenção

Importante: Node/NPM e GitHub Pages

Conteúdo de referência

GitHub Pages não mantém um processo Node.js executando no servidor. NPM pode ser usado durante o desenvolvimento, mas este site não depende dele.

Terminal

Versões

node -vMostra a versão do Node.js.
npm -vMostra a versão do NPM.
Projeto

Criar package.json

npm initAssistente de criação.
npm init -yCria usando valores padrão.
Pacotes

Dependências

npm installInstala dependências listadas no package.json.
npm install pacoteInstala um pacote.
npm install -D pacoteInstala como dependência de desenvolvimento.
npm uninstall pacoteRemove um pacote.
Scripts

Scripts

Scripts ficam em package.json e variam conforme o projeto.

Terminal
npm run
npm run dev
npm run build
npm start

npm run é útil para listar os scripts realmente disponíveis.

Manutenção

Atualização e auditoria

npm outdatedMostra dependências desatualizadas.
npm updateAtualiza dentro dos intervalos permitidos.
npm auditVerifica vulnerabilidades conhecidas.
npm audit fixTenta aplicar correções compatíveis.
Git

O que enviar ao Git

Normalmente, node_modules/ não deve ser versionado. Mantenha package.json e, quando aplicável, package-lock.json.
